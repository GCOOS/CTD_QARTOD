# WS24258 CNV and QC configuration

This directory is the dataset-owned configuration for the WS24258 cruise.
`cnv_mapping.json` was generated by inspecting all 90 CNV files in the cruise;
all 90 headers were valid.

## Current status

- `cnv_mapping.json` maps all 24 science sources from their stable CNV comments;
  all 90 files were inspected and no entry remains in `review`.
- Publication metadata and sensor links are explicit `null` placeholders for
  human completion; conversion ignores placeholders left untouched.
- QC categories use the generated destination names. Sensor ranges, spike
  limits, rate-of-change limits, climatology, station coordinates, and location
  tolerance remain empty or disabled until reviewed for WS24258.
- `flSP`, `flag`, and `pumps` declare no unit, so the mapping invents none.
- Flat-line settings retain the project template values and should be reviewed
  before the first production QC run.

## Planned workflow

Run commands from the repository root:

```bash
PYTHONPATH=. uv run python main.py convert-cnv \
  '/Volumes/Crucial X9/CTD_QARTOD/cnv_data/WS24258' \
  --mapping config/ws24258/cnv_mapping.json \
  --output output/WS24258_CNV

PYTHONPATH=. uv run python main.py qc \
  --profile config/ws24258/dataset_profile.json
```

Conversion writes source NetCDF under `output/WS24258_CNV`. Duplicate-mode QC
will preserve that source and write QC output under `output/WS24258_QC`.
